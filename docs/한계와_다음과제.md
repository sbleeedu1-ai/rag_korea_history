# 한계와 다음 과제

최종 측정(2026-10-08) 뒤 남은 실패, 측정 뒤 시험한 것, 아직 하지 않은 개선 후보를 모았습니다. 실패 문항의 자세한 분석은 [오답노트](기록/오답노트.md), 시도와 결정의 순서는 [작업기록](기록/작업기록.md)에 있습니다. 아래 후보는 모두 **시험하지 않은 제안**입니다.

이 문서는 2026-09-29부터 10-08까지의 전체 검토·원인 분석 기록(`전체검토.md`)과 인계 문서의 개선 후보 표를 합친 것입니다. 이미 반영된 항목은 지우고 남은 일만 적었습니다.

**정리하면**: 이름을 그대로 쓴 질문은 거의 다 맞히지만, **한능검식으로 이름을 가리고 단서만 주면 검색이 놓칩니다**(홀드아웃 키워드 뺀 질문 1/3). 답변 모델이 받은 자료 밖에서 지어낸 경우는 없었습니다.

드물게 나온 실패: 자료 밖 일반 지식(HN02), 다른 언어·내부 메모 출력(B7·C8·C6), 상소 반박 내용 누락(C1). 같은 설정 3회 실행의 흔들림은 단발 113-114/115, 대화 47-48/50입니다.

### 서비스

화면에서 아직 하지 않은 것(저장·이어 하기, 해설자 자동 전환, 인물 왕복 자동 검사, 사실 카드 구절 제한, 목표 체크 정확도 측정 등)은 [서비스설계](서비스설계.md) 7절에 있습니다. 명령 없이 해설·인물을 오가는 대화의 완료 조건(사용자 확인, [148]-[150]):

- "실제 역사에서는 어떻게 됐어요?"에는 해설자로 답하고, 이어지는 "그다음에는요?"도 해설을 이어 간다(**사용자가 특히 중요하다고 함**).
- "영감은 왜 반대하셨나요?"처럼 인물을 부르면 인물로 돌아간다.
- 해설자가 말한 미래 정보를 인물이 아는 사실로 쓰지 않는다.

지금 코드(`chat.is_out_of_role`)는 이번 문장만 보므로 해설 뒤 "그다음에는요?"는 인물에게 갑니다.

## 4. 성과를 말할 때 주의

- 단발 115개는 **개발셋 67개 + 같은 24개 사실을 두 표현으로 물은 48개**입니다. 서로 다른 사실 115개나 독립 홀드아웃이 아닙니다. 독립 검증은 홀드아웃 v2 20문항(한 번 실행)뿐입니다.
- 개발 성적은 Claude가 합의 기준([210])으로 채점한 것이고 사용자 전수 확인이 아닙니다. 홀드아웃 v2는 Claude + 사용자 채점입니다.
- 사람 검수 "242곳"은 검수 항목 묶음(6 + 90 + 25 + 121)이며 "803개 번역 검수 완료"가 아닙니다. 자동 시점 검사 통과는 회귀 방지이지 누설 0 보증이 아닙니다.
- 화면의 추천 질문·목표 체크·튜토리얼은 측정하지 않았습니다. 튜토리얼 장면은 개발 시나리오 A·B·C와 같은 장면이라, 서비스가 통한다는 근거로는 두 번째 사건 결과를 씁니다.
