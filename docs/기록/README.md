# 기록

지금 코퍼스와 코드가 **왜 이렇게 됐는지의 원본 기록과 근거 표**입니다. 앱은 이 폴더를 읽지 않습니다. 설명 문서는 한 단계 위 `docs/`에 있고, 실험 산출물은 `results/<날짜>_<실험 이름>/`에 있습니다.

| 위치 | 무엇 |
|---|---|
| `작업기록.md` | 시간순 기록: 누가 무엇을 제안하고 사용자가 무엇을 정했나, 결과. 끝에 새 항목을 더함 |
| `오답노트.md` | 실험마다 틀린 문항과 원인 분석 |
| `데이터구축/` | 기사를 고른 근거: `고른기사목록.csv`(뽑을 기사 132건, `extract_articles.py`가 읽음), 한능검 심화 65-79회 조선 문항 집계 3개(회차·번호·우리말 요약만), 데이터 표 `데이터표.xlsx`. 설명은 [데이터](../데이터.md) 1절 |
| `데이터가공/` | 정제·청킹·번역 확인용 표: 청크 통계, 정제 기록, 수동 검사표, 화자 라벨 표본 검사, 쉬운 말 풀이 사전 대조, 원문 오자, 밝힘 괄호 보충, 번역 수정 대기. 설명은 [데이터](../데이터.md) 2절과 [규칙서](../정제청킹_규칙서.md) |
| `평가셋/` | 검증 재료 나누기(A는 검증셋 v1, **B는 봉인했다가 홀드아웃 v2에 씀**), 검증 질문 표현 후보, 홀드아웃 v2 후보 두 판(Claude판·OpenAI판). 설명은 [데이터](../데이터.md) 3절 |

`청크통계`의 숫자는 규칙서 6-1, `수동검사표`의 판정은 규칙서 6-2에 옮겨 적었습니다. `scripts/chunk_articles.py --tag <새 이름>`을 돌리면 `데이터가공/`에 새 세트가 생깁니다.
