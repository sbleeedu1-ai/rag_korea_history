# 실험 설계

## 확인하려는 것

검수한 자료를 받은 GPT-4o mini가 어느 수준까지 답하는지, 그리고 우리가 추가한 설계(검색, 시점 필터, 해설자 분리)가 실제로 오류를 줄이는지.
결과는 사건 하나(기사 7건)에서의 기술적 가능성과 개선 효과만 보여 줍니다. 다른 사건으로 일반화하지 않습니다.

## 조건

| 조건 | 모델에 주는 자료 | 확인할 것 |
|---|---|---|
| A | 원문(한문) 23청크 전체 | 한문을 바로 읽고 답할 수 있는가 |
| B | 자체 번역문 23청크 전체 | 사전 번역이 도움이 되는가 |
| C | 같은 번역문을 DB에서 검색한 상위 4개 | 필요한 근거를 찾아 전달하는가 |
| D1 | C + 인물 역할일 때 장면 시점 이후 청크를 검색에서 제외 | 시점 필터가 누설을 줄이는가 |
| D2 | D1 + 역할 밖 요청은 해설자가 따로 답하고 인물 이력에서 제외 | 이력 분리가 오염(B6)을 줄이는가 |

공통: 모델 `gpt-4o-mini-2024-07-18`, temperature 0, 같은 규칙 문장과 같은 자료 머리말(청크 ID·기사 ID·문단·기록일·화자).
다회차 시나리오는 설정 문구를 첫 사용자 메시지로 넣고(0번 턴, 집계 제외) 한 대화로 이어 갑니다.

결과 해석 기준(미리 정함)
- B부터 안 되면: 번역·프롬프트·모델 문제를 먼저 확인
- B는 되는데 C가 떨어지면: 검색·청킹 개선
- C보다 D1·D2의 누설이 줄면: 서비스 설계의 실증 근거
- 전부 잘되면: 자료를 늘리고 학습 흐름(취재 수첩) 구현으로 이동

## 데이터

- 원문: 공공데이터포털 조선왕조실록 원문 XML(공공누리 1유형·AI유형)에서 기사 7건
  `wda_12512030_002, wda_12602016_001, wda_12602020_001, wda_12602021_001, wda_12602028_001, wda_12603002_001, wda_12809029_004`
- 청킹: 문단 단위, 긴 문단은 주장·화자 전환(上曰, 萬理等對曰, 上又敎曰, 翌日)에서 분할. 원문 전체를 빈틈·중복 없이 덮는지 테스트로 확인.
- 번역: 기사 맥락을 보고 자체 번역(AI 초벌). 공식 국역은 복사하지 않음.
- 사건 시점(`event_order`): 기사 날짜와 별도로 청크 내용이 일어난 시점

| order | 시점 |
|---|---|
| 10 | 1443년 12월 창제 기록 (是月, 날짜 확정 안 함) |
| 20 | 1444-02-16 《운회》 번역 명령 |
| 30 | 1444-02-20 상소 제출 (시나리오 A·B, 단발 Q1-Q3의 장면) |
| 31 | 1444-02-20 세종 논박·하옥 (시나리오 C의 장면) |
| 40 | 1444-02-21 석방·정창손 파직·김문 국문 전지 (2월 20일 기사 9문단 翌日 이후 + 10문단) |
| 41 | 1444-02-21 김문 처벌 |
| 50 / 60 | 1444-02-28 초수리 거둥 / 03-02 도착 |
| 70 | 1446년 9월 훈민정음 완성 (是月) |

## 평가

- 단발 25문항: 기존 함정 20문항 + 일반 학습 5문항(G1-G5)
- holdout 5문항(H1-H5): 튜닝에 쓰지 않고 `--allow-holdout`으로만 실행
- 다회차: 시나리오 A·B·C (각 10턴)
- 자동 점검(힌트): 미래 정보 단어, 필수 단어 누락, **원문에 없는 한자 4자 이상 인용**, 정답 근거 청크 검색 여부
- 최종 판정: `grade-sheet` CSV에 사람이 정답/부분/오답/적절한 보류/부적절한 보류로 기록

판정 규칙(범용 AI 테스트에서 확정한 것 그대로)
- 추측임을 밝히면 누설 아님. 전제를 처음 수용했다가 번복하면 실패.
- 실제 사건 시점이 장면 이전이면 허용(前此로 표시된 과거 발언 등).
- 장면 이후 기록을 전제 교정용으로라도 사실로 제시하면 누설.
- 김문 국문 전지는 이튿날의 명령으로 판정.
- B5는 "역할 밖 답변을 인물 말투와 섞지 않았는가"가 공통 기준. B6 개선을 이력 분리 효과로 해석하려면 B5가 실제로 미래 정보를 말했는지 먼저 확인.
- 기존 채점표 Q3의 하위지 관직은 부교리로 수정.

## 아직 안 한 것

- 실제 API 실행과 채점
- 번역 사람 검수, 용어집(고유명사·호칭 목록)을 넣은 재번역 비교
- 제안서의 청킹 비교(고정 길이+겹침 vs 화자 전환)
