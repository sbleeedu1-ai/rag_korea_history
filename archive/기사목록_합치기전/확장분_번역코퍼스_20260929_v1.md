# 문서 확장 125건 번역 코퍼스 (v1, 2026-09-29)

규칙서 v1.1(`docs/정제청킹_규칙서.md`)로 자른 확장 기사 125건의 청크 769개를 모두 번역해, 기존 파일럿 코퍼스(`data/corpus.jsonl`)와 **따로** 저장했습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `data/expansion/corpus_20260929_v1_규칙서.jsonl` | 확장분 코퍼스. 한 줄 = 청크 하나(769줄) |
| `data/expansion/번역_20260929_v1/001-012.jsonl` | 청크별 번역 원본(묶음 12개). 코퍼스는 이 파일들로 다시 만듦 |
| `scripts/build_corpus.py` | 청크 초안 + 번역 → 코퍼스(지금은 파일럿 포함 132건 `data/corpus.jsonl`). `--dump 번호 개수`로 기사 원문을 청크 단위로 볼 수 있음 |

- 청크 원문: `data/chunk_trial/청크초안_20260929_v1b_132건_규칙서시험.jsonl` 가운데 확장분 125건(파일럿 7건 제외)을 그대로 씀. 청크 경계는 바꾸지 않음.
- 다시 만들기: `python scripts/build_corpus.py` (2026-09-29부터 132건 전체 코퍼스 `data/corpus.jsonl`을 만듦, 작업기록 [87])

## 청크 한 줄의 칸

규칙서 5장의 칸에 번역 단계(4-6 T7) 칸을 채웠습니다.

| 칸 | 내용 |
|---|---|
| `translation` | 한문 원문만 보고 한 AI 초안(`translation_status: ai_draft`). 국역·신역은 보지도 넣지도 않음(T1) |
| `speaker` | 한글(漢字) 이름. 규칙서 자동 초안이 틀린 곳은 고침(`speaker_draft`에 원래 초안 보존) |
| `quoted` | 청크 안에서 말이 인용된 사람·글 |
| `event_date` / `known_from` | 사건 시점 / 알려진 시점. 사론·졸기는 `known_from`이 "인물 모름" |
| `header` | 머리말. "[날짜 · 왕 재위년 · 제목 · 말한 사람 · 인용]", 한글 이름으로 다시 만듦. 윤달은 "윤2월"처럼 표시 |
| `note` | 사람용 메모(고친 화자, 시점 근거, 원문 오자, 확인할 곳). 모델에게 보내지 않는 칸 |

## 번역하면서 지킨 것 (규칙서 4-6)

- T2 생략된 주어를 괄호로 보충. 예: "(우왕이) 봉주에 머물렀다"
- T3 괄호는 주어·대상 보충에만 씀
- T4 인물·관직·책은 처음 나올 때 한글(漢字)
- T5 원문 글자를 고쳐 읽은 곳은 note에 적음. 예: `戚斷光` → 척계광
- T6 사관 서술은 따옴표 밖, 인물의 말은 따옴표 안
- 편찬 때 붙은 묘호는 그 시점 호칭을 괄호로 적음. 예: 1453년 장면의 "세조" → 수양대군(首陽大君, 세조)

## 번역하면서 본 규칙서 v2 후보

7가지를 찾았고, 규칙서의 "v2에서 고칠 것" 표(`docs/정제청킹_규칙서.md` 8장)로 옮겨 한 곳에서 관리합니다. 대답(對曰) 화자 오류는 ①의 예시로, 나머지 6가지는 ⑩-⑮입니다.

## 하지 않은 것

- 사람 검수: 번역은 모두 AI 초안. note의 "확인 필요" 6곳과 화자를 고친 90곳부터 보면 됨
- `data/corpus.jsonl`·`sillok_rag/`·평가셋: 건드리지 않음. 이 코퍼스를 검색에 붙이는 것은 다음 작업(새 코퍼스 연결)에서 할 일
- 테스트: 이 환경에 pytest가 없어 돌리지 못함(코드 변경은 새 스크립트 하나뿐)
