# 정제·청킹·메타데이터 규칙서 (v2, 2026-09-30)

실록 기사를 챗봇이 찾아 쓸 수 있는 조각(청크)으로 만드는 규칙입니다. 로드맵 3단계(정제 규칙·청킹·메타데이터·청크 통계·수동 검사표) 산출물입니다.

> **v2(2026-09-30)**: 사람 검수 242곳([작업기록](../../docs/기록/작업기록.md) [118])에서 나온 문제로 규칙을 고치고 다시 잘랐습니다(793 → **803청크**, 처음 804에서 검사표 v2로 1곳 합침). 바뀐 것은 **[10장](#10-v2에서-바뀐-것-2026-09-30)** 에 모았고, 1-9장은 v1.1(2026-09-29) 기록으로 두었습니다. 숫자가 다르면 10장이 지금 값입니다.
번역은 하지 않았습니다(기사 목록이 확정된 뒤 한 번에 할 예정). 여기서는 **한문 원문만** 다룹니다.

## 1. 전체 흐름

```
실록 ZIP(국사편찬위원회 XML, 한문)
  │ ① 정제: 깨진 글자·교감 표시 정리, 필요 없는 주석 빼기          (3장)
  │ ② 나누기: 말하는 사람·시점·인용 단위로 청크 만들기             (4장)
  │ ③ 메타데이터: XML에서 가져온 칸 + 새로 붙인 칸                (2장, 5장)
  ▼
청크 초안(원문)  ← 여기까지가 이 규칙서의 자동 단계 (data/청크/)
  │ ④ 번역(AI 초안) + 화자 한글 이름 + 사건 시점·알려진 시점 채우기   ← 기사 목록 확정 뒤
  │ ⑤ 머리말 + 번역문을 임베딩, BM25에도 같은 글
  ▼
Chroma DB
```

## 2. XML에서 그대로 가져오는 것

XML 원본에 이미 들어 있어서 규칙 없이 복사하면 되는 칸입니다. (ZIP 안 `history.dtd`와 실제 XML 전체를 훑어 확인)

| 청크 칸 | XML 어디에 | 예 | 비고 |
|---|---|---|---|
| `article_id` | `level5/@id` | wda_12602020_001 | 태조실록 총서는 `level3` 이 기사 단위 |
| `record_date` | `dateOccured/@date` | 1444-02-20L0 → 1444-02-20 | 끝의 **L1은 윤달**(예: 세종 26년 권에 108건). `leap_month` 칸으로 따로 둠. 총서는 날짜 없음 |
| `day_ganji` | 본문 첫머리 `○庚子/` | 庚子 | 본문에서 떼어 칸으로 옮김(`朔己亥/`처럼 초하루 표시가 붙기도 함) |
| `title_ko` | `mainTitle` | 집현전 부제학 최만리 등이… | 국사편찬위원회가 붙인 **한글 제목**. 번역문이 아니라 기사 요약 제목 |
| `source` | `source` 첫째 | 태백산사고본 世宗實錄 33책 103권 19장 B면 | |
| `king`, `reign` | 출처의 실록 이름 + 기사 ID | 세종, 세종 26년 | ID 5-7번째 글자가 재위 연도(`wda_1 26 02 020`) |
| `subjects` | `subjectClass` | 어문학-어학(語學), 사법-행형 | 한 기사에 여러 개 |
| `persons` `places` `books` | `index/@type` = 이름·지명·서명 | 崔萬理, 椒水里, 《三綱行實》 | 청크에 실제로 나오는 것만 청크에 붙임. 색인 번호(`ref`)도 있어 나중에 인물 사전과 연결 가능 |
| 편찬자 주석 | `annotation type="원주"`, `소자쌍행` | 【其母入江都故也。】 | 원문의 일부라 **【】째 본문에 남김** |
| 사론 | `postScript type="史論"` 또는 【史臣曰…】 | 【史臣曰: …】 | 본문과 **따로 청크**로 (4-4의 '인물이 모르는 기록') |

XML에 **없는** 것: 기사 안에서 누가 말하는지, 그 말이 실제로 언제 있었던 일인지, 인물이 언제부터 그 사실을 알았는지. 이게 4장의 규칙이 필요한 이유입니다.

### 4-1. 청크를 나누는 순서

1. **기사 경계**: 청크는 기사를 넘지 않는다.
2. **문단**: XML 문단(`paragraph`)이 첫 단위.
3. **말머리**: 문단 안에서 `X曰:` `X啓曰:` `X議:` `X啓:` `X言:` 이 나오면 그 구절 시작에서 끊는다. 따옴표 안(남의 말 속)의 曰은 끊지 않는다.
   - 말머리만 있는 문단(`…上疏曰:`)은 뒤따르는 본문 문단과 합친다(상소문은 보통 다음 문단부터 본문).
   - 말이 끝난 뒤 서술이 60자 이상 이어지면 서술을 따로 떼어 낸다.
4. **시점이 바뀌는 말**: `翌日`(다음 날) `明日` `初,`(이전에) `先是` `前此` `至是` `是後` `其後` `後日` 로 시작하는 곳에서 끊는다. 이 조각은 짧아도 앞에 붙이지 않는다(파일럿 c15 "翌日, 命釋之…"가 따로 있어야 했던 이유).
5. **인용 단위**(4-3): 한 사람의 말 안에 다른 사람 말 인용이 2개 이상이면 인용마다 쪼갠다.
6. **길이**: 400자(공백 뺀 한자 수)가 넘으면 `一,`(상소의 조목) 시작이나 문장 끝(。?!)에서 비슷한 길이로 나눈다. 30자 미만 조각은 앞 조각에 붙인다(인용 단위·기사 전체·시점 바뀜은 예외).
   - 400·30의 근거: 파일럿 23개가 원문(공백 뺀 한자) 기준 11-413자, 평균 150자였고(번역문 기준으로는 평균 364자) 그 크기로 검색이 16-19/21 맞았음. 이보다 길면 한 청크에 주제가 여럿 섞임.

### 4-2. 화자

자동으로 초안을 달고, 확실하지 않으면 `화자확인` 표시를 붙입니다. **한글 이름으로 바꾸는 건 번역 단계**에서 합니다(지금은 원문 한자 그대로: 崔萬理 → 번역 때 최만리).

| 화자 종류 | 알아보는 법 (말머리 앞 구절) | 예 |
|---|---|---|
| 임금 | `上曰` `傳曰` `敎曰` `御製` `備忘記` `綸音` | 上曰: → 세종 |
| 왕실 | 大王大妃·王大妃·世子 등 | 大王大妃曰: → 대왕대비 |
| 신하 | 색인에 있는 사람 이름 | 萬理等對曰: → 萬理 등 |
| 관청 | 備邊司·義禁府·戶曹 등 | 義禁府劾啓: → 의금부 |
| 상소 | `上疏` `上箚` `交章` `封疏` | 崔萬理等上疏曰: → 최만리 등(상소) |
| 문답 | 짧은 말(30자 미만)이 여럿 붙어 한 청크에 말한 사람이 둘 이상 | 景禧曰 … 上曰 … → 신경희·선조 |
| 이어서 | `又曰` `其一曰` 처럼 앞사람이 계속 말함 | 앞 화자를 물려받음 |
| 사관(서술) | 말머리가 없는 부분 | 車駕至椒水里。 |
| 사관(사론) | `史臣曰`, `postScript` | 【史臣曰: …】 |
| 기타(확인필요) | 위 어디에도 안 맞음 | 覘者曰(정탐꾼), 有人自泥城來 … |

132건 결과: 신하 259 · 서술 163 · 문답 128 · 임금 108 · 상소 47 · 왕실 26 · 관청 21 · 사론 5 · 기타 36(4.5%).

### 4-3. 인용 단위 쪼개기 (사용자와 합의한 규칙)

**규칙**: 한 사람이 말하는 도중 다른 사람의 말(`X曰: ‘…’`)을 2개 이상 인용하면, **"인용 + 그 인용에 대한 화자의 말"** 을 한 청크로 쪼갭니다. 인용이 시작되는 곳에서 기계적으로 자르지 않고, 다음 인용이 시작되기 직전까지를 한 덩어리로 합니다. 청크에 `quoted`(인용된 사람) 칸을 붙입니다.

**왜**: Q4("불가하지 않다"고 말한 사람 = 김문)가 조건 C에서 계속 틀렸습니다. c13 한 덩어리 안에 김문 인용은 한 줄뿐이고 나머지는 정창손·《삼강행실》 이야기라, 임베딩 검색에서 c13이 13위로 밀렸습니다. 지금 검색용 글은 "기사 제목 / 화자 + 번역문"뿐이라(`sillok_rag/corpus.py`의 `search_text`) 인용된 사람 칸을 따로 달아도 검색에는 안 들어갑니다. 그래서 쪼개거나 머리말에 넣어야 합니다.

**파일럿 c13에 적용한 결과** (자동):

| 새 청크 | 화자 | 인용된 사람 | 원문 |
|---|---|---|---|
| 13-1 (…-11) | 세종 | 金汶(김문) | 上曰: "前此金汶啓曰: ‘制作諺文, 未爲不可。’ 今反以爲不可。 |
| 13-2 (…-12) | 세종 | 鄭昌孫(정창손) | 又鄭昌孫曰: ‘頒布《三綱行實》之後, … 何必以諺文譯之, 而後人皆效之?’ 此等之言, 豈儒者識理之言乎? 甚無用之俗儒也。" |
| 13-3 (…-13) | 세종 | — | 前此, 上敎昌孫曰: "予若以諺文譯《三綱行實》, … 必輩出矣。" 昌孫乃以此啓達, 故今有是敎。 |

13-3은 인용 규칙이 아니라 3번 규칙(말머리 `上敎昌孫曰`)과 4번 규칙(`前此` = 이전에)으로 따로 떨어졌습니다. 합의 때 예로 든 "13-1 김문 / 13-2 정창손 / 13-3 배경"과 같은 모양입니다.

132건 전체에서 인용 단위로 쪼개진 청크는 32개입니다. 인용이 하나뿐이면 쪼개지 않습니다(쪼개도 같은 덩어리).

### 4-4. 사건 시점과 알려진 시점

청크마다 날짜 칸을 셋으로 나눕니다.

| 칸 | 뜻 | 기본값 | 누가 채우나 |
|---|---|---|---|
| `record_date` | 기사에 적힌 날짜 | XML 그대로 | 자동 |
| `event_date` | 그 일이 실제로 일어난 때 | = record_date | 번역 단계(AI 초안), `시점확인` 표시 청크만 사람 확인 |
| `known_from` | 인물들이 그 사실을 **알게 된** 때 | = event_date | 〃 |

역할 대화의 시점 필터(D1·D2)는 파일럿 때 `event_order`(사건 순서)로 걸렀고, 새 코퍼스 연결(작업기록 [87])부터 **`known_from`으로** 거릅니다. 그래야 오답노트 ⑥·⑦ 같은 실패가 줄어듭니다(오답노트 번호는 `archive/파일럿_1-7차/docs/오답노트.md` 기준).

| 사례 | record_date | event_date | known_from | 왜 따로 적어야 하나 |
|---|---|---|---|---|
| 파일럿 c15 "翌日, 命釋之…" (석방) | 1444-02-20 | **02-21** | 02-21 | 2월 20일 기사 안의 다음 날 이야기. 2/20 장면의 최만리는 모름 |
| c14 하옥된 7명 명단 (오답노트 ⑦) | 02-20 | 02-20 오후(하옥) | **02-20 상소 때** | 명단은 하옥 기록에만 있지만 "누가 상소에 이름을 올렸나"는 상소 때 이미 앎. 필터가 이걸 막아 "박팽년도 함께했지요?"를 못 바로잡음 |
| c09 초수리 거둥 예정 / c17 실제 거둥 (오답노트 ⑥) | 02-20 / 02-28 | 02-20 / 02-28 | 02-20 / 02-28 | '예정'은 상소 때 알고, '실제로 갔다'는 2/28부터. "지금 초수리에 계시지요?"엔 "아직 안 갔다"가 정답 |
| 사론 【史臣曰…】 | 기사 날짜 | — | **후일 기록** | 실록 편찬 때(왕이 죽은 뒤) 사관이 쓴 평가. 역할 대화에서는 늘 빼고, 해설자만 씀 |
| 졸기(인물이 죽을 때 쓴 평생 요약, 예: 송시열 졸기) | 죽은 날 | 평생 | **후일 기록** | 젊은 시절 장면의 인물에게는 미래 정보 |

**자동으로 할 수 있는 것**: 시점 신호 단어(翌日·明日·初,·先是·前此·至是·是後·其後·後日·旣而·已而·是月·是歲·今年·去年·前日)가 있으면 `시점확인` 표시를 붙입니다. 132건에서 121개(15%)에 붙었고, 이 청크만 사람이 보면 됩니다. 말 속의 '去年·今年'처럼 사건 시점과 무관한 경우도 걸리니(검사표 4번), 표시는 "볼 곳" 목록일 뿐입니다.

### 4-5. 맥락 머리말

청크 앞에 한 줄을 붙여, 짧은 청크도 "언제, 무슨 일, 누가"를 알 수 있게 합니다. **임베딩과 BM25 모두 "머리말 + 번역문"** 으로 만듭니다.

형식: `[날짜 · 왕 재위년 · 기사 제목 · 말한 사람: 화자 · 인용: 인용된 사람]`

```
[1444년 2월 20일 · 세종 26년 · 집현전 부제학 최만리 등이 언문 제작의 부당함을 아뢰다 · 말한 사람: 세종 · 인용: 김문]
[1651년 8월 4일 · 효종 2년 · 이완을 특별히 서용하여 어영 대장에 임명하다 · 말한 사람: 사관(서술)]
```

- 두 번째는 원문이 `特敍李浣, 復拜御營大將。` 12자뿐인 기사입니다. 머리말이 없으면 번역문 한 줄만으로는 무슨 맥락인지 검색에 잡히기 어렵습니다.
- 기사 제목은 국사편찬위원회가 붙인 요약 제목이라 번역문(국역)이 아닙니다. 그래도 한 기사의 모든 청크에 똑같이 붙으므로, 기사 안에서 청크를 구별하는 건 화자·인용 칸이 합니다.
- 화자·인용된 사람은 번역 단계에서 한글 이름으로 바꿉니다. 인물이 그 시점에 불리던 호칭도 괄호로(검사표 9번: 1453년의 世祖는 아직 '수양대군').

### 4-6. 번역 단계 규칙

청크를 자른 뒤 청크마다 번역하면서 지키는 규칙입니다. 132건(청크 793개)을 번역할 때 이 규칙을 씁니다. 파일럿 번역 점검(`archive/파일럿_1-7차/docs/파일럿번역_수정제안_20260929.md`, 23청크 중 18개에 고칠 곳)에서 나온 공통 문제를 규칙으로 옮겼습니다.

| # | 규칙 | 예 (파일럿) | 왜 |
|---|---|---|---|
| T1 | 한문 원문만 보고 번역한다. 국역·신역은 보지도 넣지도 않는다 | — | 저작권, 기존 방식 유지 |
| T2 | **생략된 주어를 괄호로 보충한다.** 한문은 주어를 자주 빼는데, 청크로 잘리면 앞 문맥이 사라진다. 행위자가 앞 문장과 바뀌거나 청크 밖에 있을 때 `(김문이)`처럼 괄호로 채운다. 누가 누구에게 한 일인지 모르면 대상도 채운다 | c13 "지금은 **(김문이)** 도리어 불가하다고 한다" / c15 "이튿날 **(임금이)** 명하여 **(의금부에 갇힌 최만리 등 7명을)** 석방하게 하되" | 7차 실험 C2 오답: 주어가 빠진 문장을 모델이 질문 속 "최만리"로 채움. 바로 뒤에 "또 정창손은"이 나와 헷갈리기 더 쉬움 |
| T3 | 괄호는 **원문에 없는 말**이라는 표시다. 주어·대상 보충에만 쓰고, 해석을 괄호로 끼워 넣지 않는다 | c12 "글자 모양(을 본뜬 것)이 아닙니다"의 "(을 본뜬 것)"은 원문에 없는 해석 → 빼기 | 괄호 속 해석이 원문의 주장처럼 검색된다 |
| T4 | 인물·관직·책 이름은 청크에서 **처음 나올 때** `한글(漢字)`로 적는다 | 최만리(崔萬理), 부제학(副提學), 《삼강행실(三綱行實)》 | 같은 소리의 다른 인물(이개 등) 구별, 한자로 검색 |
| T5 | 원문 글자를 말없이 바꾸지 않는다. 글자 교정은 정제 단계(R5·R6, XML 교감주)에서만 하고, 번역에서 다른 글자로 읽으면 note에 근거를 남긴다 | c20 원문 蚪를 번역에서 虯로 바꿔 적음 | 원문 한자로 검색하면 번역과 어긋남 |
| T6 | 청크 안에서 목소리가 바뀌면 번역에 드러나게 한다(사관 서술은 따옴표 밖, 인용은 따옴표 안). 화자 칸과 다르면 화자 칸을 고친다 | c14 끝의 "遂下…于義禁府"(사관 서술)가 세종 발언 칸에 섞임 | 서술이 인물의 말로 검색된다 |
| T7 | 번역하면서 규칙서가 비워 둔 칸을 채운다: `speaker`·`quoted`를 한글(漢字)로, `event_date`·`known_from`(4-4, `시점확인` 표시 청크는 꼭), `note`(사람용 주의 메모) | c15 event_date = 1444-02-21 | 머리말(4-5)과 시점 필터가 이 칸을 쓴다 |

T2는 **청크를 자른 뒤에** 적용합니다. 같은 문장이라도 앞 문장이 같은 청크에 있으면 보충이 필요 없고, 청크 경계 바로 뒤라면 필요합니다. 그래서 인용 단위로 쪼갠 청크(4-3)에서는 거의 항상 필요합니다(13-1은 "今反以爲不可"로 끝남).

### 6-3. 예시

**① 여러 사람이 짧게 주고받는 장면 → '문답' 청크** (양재역 벽서, 1547년 명종 2년)

```
[1547년 9월 18일 · 명종 2년 · 부제학 정언각이 양재역 벽에 붙은 익명서를… · 말한 사람: 趙彦秀·명종]
都承旨趙彦秀以三公意啓曰: "右贊成閔齊仁、判中樞府事許磁、禮曹判書尹元衡, 亦請命召。" 傳曰: "可。"
```
도승지가 부를 사람을 아뢰고 임금이 "좋다" 한 마디로 답하는 장면입니다. 대답만 따로 떼면 "可。" 한 글자라 의미가 없어서 질문과 한 덩어리로 둡니다.

**② 사론은 따로** (같은 기사 마지막)

```
[… · 말한 사람: 사관(사론)]
【史臣曰: "芑等旣以乙巳之人爲逆賊, 欲實其事, 至於請殺中廟之子, 甚矣!"】
```
이기 등을 비판하는 사관의 평가입니다. 편찬 때 쓴 글이라 `known_from` = 후일 기록. 역할 대화 자료에서는 빼고 해설자만 씁니다.

**③ 시점이 바뀌는 곳에서 끊기** (선혜청 설치, 1608년 광해군 즉위년)

```
-01 [… · 말한 사람: 李元翼]  設宣惠廳。 初, 領議政李元翼議: "以各邑進上貢物爲各司防納人所搪阻, … 請劃一施行。" 從之。 以傳敎中有宣惠之語, 以名其廳。 …
-02 [… · 말한 사람: 사관(서술)]  是後守令不得人, 則法外加收, 亦不能禁, … 然畿甸田結之役, 賴此少蘇矣。
```
-02는 `是後`(이 뒤로) 로 시작하는, 선혜청이 생긴 뒤의 결과 평가입니다. 1608년 장면의 이원익은 모르는 내용이라 `event_date`·`known_from`을 뒤로 적어야 합니다.

**④ 아주 짧은 기사 + 머리말**: 4-5의 이완 임명 기사(12자).

**⑤ 인용 단위**: 4-3의 c13.
